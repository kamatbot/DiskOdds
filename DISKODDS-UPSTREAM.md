# DiskOdds upstream provenance

DiskOdds contains the full source, assets, tests, and history of [colinvkim/Radix](https://github.com/colinvkim/Radix). The initial import pinned `14a76df4fe626dcdefc4f2abbc868dff4bbbd6e4` (2026-09-20). The inherited explorer now includes upstream `main` through `df1235bfb05acb7a678718166491bcc27817d95d` (2026-10-10): selective Unicode scan keys, short-name sort preparation, native file dragging, read-only browsing, discard-pile undo, and the file-browser and inspector fixes that followed. DiskOdds-only cleanup behavior is not part of that upstream tree.

The original MIT license and Colin Kim's attribution are retained unchanged in `LICENSE`. The original README is preserved at `docs/RADIX-UPSTREAM.md`. DiskOdds adds a developer-cleanup workspace, independent bundle identity, and tests. The inherited Radix auto-update feed and public signing key are removed; no upstream updater is started.

Cleanup confidence percentages are heuristic rule scores, not measured probabilities or deletion guarantees.
